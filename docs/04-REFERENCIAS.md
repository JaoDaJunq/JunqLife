# Referências públicas

## Traccar Client SDK
Uso: background GPS, buffer offline, retry, stop detection e integração React Native.
Licença observada: Apache-2.0.
https://github.com/traccar/traccar-client-sdk

## Traccar Server / Web
Uso como referência para mapa ao vivo, eventos, geofences e arquitetura de tracking.
https://github.com/traccar/traccar
https://github.com/traccar/traccar-web

## OwnTracks
Uso como referência de consentimento, privacidade, protocolo e compartilhamento familiar.
https://github.com/owntracks/android
https://github.com/owntracks/recorder
https://github.com/owntracks/frontend

## Dawarich
Uso como referência de timeline, visitas, viagens e histórico geográfico.
https://github.com/Freika/dawarich

## Regra de implementação
Antes de desenvolver um recurso complexo de tracking, revisar primeiro se Traccar, OwnTracks ou Dawarich já resolvem o mesmo problema e documentar o que foi adaptado versus criado do zero.
