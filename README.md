# JunqLife

Base técnica do JunqLife, um app de localização compartilhada inspirado em Life360, com foco em consentimento, privacidade e reaproveitamento de componentes maduros.

## Stack definida
- React Native + Expo Development Build
- Traccar Client SDK para background location
- MapLibre para mapas
- Supabase Auth
- PostgreSQL + PostGIS
- Supabase Edge Functions
- Supabase Realtime

## Marco V0.1
Dois usuários entram no mesmo círculo, autorizam localização e conseguem ver um ao outro no mapa com posição atual e última atualização.
